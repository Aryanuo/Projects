# 🎮 Mini Games Collection

A collection of simple, text-based Python mini games — all running right in your terminal!  
Perfect for beginners learning Python basics like loops, conditionals, and functions.

---

## 🕹️ Games Included
- 🧠 **Number Guessing** — Try to guess the secret number!
- 🪙 **Coin Toss** — Heads or Tails? Let’s find out.
- 🎲 **Dice Roll** — Roll a virtual dice.
- ✊ **Rock Paper Scissors** — Classic hand game vs the computer.
- 🔼 **Higher or Lower** — Guess if the next number will be higher or lower!

---

## 📊 Scoreboard System
Each game updates a shared scoreboard that tracks:
- Total games played  
- Wins, losses, and draws  

Your progress is automatically saved to a `scoreboard.json` file!

---

## ⚙️ How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/Aryanuo/Mini-Games.git
2. cd Mini-Games
3. python main.py
4. Choose a game from the menu and start playing!
