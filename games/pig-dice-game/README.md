# 🎲 Pig Dice Game (Python)

A simple **command-line implementation** of the classic **Pig Dice Game**, written in Python.  
Players take turns rolling a dice to reach **50 points** — but beware! Rolling a **1** resets your turn score.

---

## 🕹️ How the Game Works

- Supports **2 to 4 players**
- Each player rolls a dice (1–6)
- If you roll:
  - **1** → Your turn ends & turn score becomes 0
  - **2–6** → Added to your turn score
- You can choose to **roll again or stop**
- First player to reach **50 points wins**

---

## 📦 Requirements

- Python 3.x  
(No external libraries needed)
